## Projetos em destaque

### Controle de Clientes

Sistema full stack para controle semanal de clientes, serviços, pendências, cancelamentos e pagamentos.

**Destaques:**

- Interface em React e TypeScript
- API REST com Node.js e Express
- Persistência em SQLite
- Cadastro, edição, listagem e exclusão de clientes
- Criação de semanas de acompanhamento
- Dados fictícios para demonstração pública
- Testes automatizados de API e interface

**Tecnologias:** React, TypeScript, Vite, Node.js, Express, SQLite, Vitest  
**Repositório:** [controle-de-clientes](https://github.com/felipeleite0/controle-de-clientes)

### Brasileirão DB

Projeto didático de banco de dados para cadastrar times e jogos fictícios do Campeonato Brasileiro, com cálculo de classificação.

**Destaques:**

- Modelagem de tabelas relacionais
- Chaves primárias e estrangeiras
- Consultas SQL com `JOIN`
- Cálculo de pontuação, vitórias, empates, derrotas e saldo de gols
- Painel local para atualizar resultados e recalcular a tabela

**Tecnologias:** JavaScript, Node.js, SQLite, SQL, HTML, CSS  
**Repositório:** [brasileirao-db](https://github.com/felipeleite0/brasileirao-db)
